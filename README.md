# Stock AI Lab

日本株・米国株のテクニカル分析（短期・中期・長期の条件比較）と仮想売買メモを行うStreamlitアプリです。分析補助専用で、自動発注・証券口座接続はありません。

## ファイル
- `app.py` : アプリ本体（画面）
- `analysis.py` : 分析ロジック（データ取得、指標計算、短期・中期・長期の条件評価、データの新旧判定）
- `verify.py` : 検証ロジック（過去データでの評価の再現、採点、集計、CSV保存・復元）
- `scan.py` : スキャンロジック（対象銘柄リスト、一括取得、ランキング、CSV出力）
- `requirements.txt` : 必要ライブラリ（動作確認したバージョンで固定）
- `tests/test_analysis.py` : 分析ロジックの単体テスト（通信はモック化しており、ネットワークなしで実行できます）
- `tests/test_verify.py` : 検証ロジックの単体テスト（ネットワークなしで実行できます）
- `tests/test_scan.py` : スキャンロジックの単体テスト（ネットワークなしで実行できます）
- `tests/manual_live_fetch_check.py` : 実データ取得の手動確認スクリプト（単体テストには含まれません）
- `.gitignore` : 不要ファイル除外

## テストの実行方法
単体テスト（ネットワーク不要）:
```
pip install -r requirements.txt pytest
python -m pytest tests/test_analysis.py -q
```
実データ取得の手動確認（実際にYahoo Financeへアクセスします。通信障害や取得制限で結果が変わることがあります）:
```
python tests/manual_live_fetch_check.py
```

## 銘柄名の表示
- 銘柄一覧と個別分析の見出しには、コードに加えて会社名も表示します（表示専用で、分析には使いません）。
- 「詳しく分析する銘柄」は、会社名とコードを併記した選択式です（例：トヨタ自動車（7203.T））。内部処理にはコードが渡ります。
- 初期銘柄（日本株4・米国株4）は内蔵の対応表から表示します。それ以外の銘柄はYahoo Financeから会社名の取得を試み、取得できなければコードのみ表示します。

## 検証（過去データでの採点、仕様バージョン1）
- 対象は初期8銘柄、データは5年分、評価日は5営業日ごとです。評価は評価日までのデータだけで再現し、未来の価格を使いません。
- 測定窓は短期5・中期20・長期60営業日。小動きの幅は短期±1%・中期±2%・長期±3%です。条件は結果を見て変更しません。変更する場合は仕様バージョンを上げます。
- 的中率の分母は的中＋不的中のみです。中立予測・実際小動き・判定保留・対象外は別々に数えます。
- 方向付き騰落率は参考値で、売買コストを含みません（実際の損益ではありません）。中立予測はその集計に含めません。
- 評価日間隔より測定窓が長いため窓は重なります。検証件数は独立した試行の数ではありません。
- 記録はCSVで保存し、CSVの読み込みで復元・合算できます。重複判定のキーは銘柄・評価日・時間軸・仕様版数で統一しています。同じキーで内容の異なる記録がある場合は競合として検出し、通知して取り込みません。
- 対象外集計（履歴不足・測定窓不足・取得失敗の理由と件数）も別のCSVで保存・復元できます。予測記録とは区別し、同じ条件の集計は合算しないことで二重計上を防ぎます。
- アプリを閉じると画面上の記録は消えるため、CSV保存が必要です。

## スキャン（主要な日本株の一括評価）

「スキャン」タブでは、主要な日本株60銘柄を一括で取得し、中期評価のスコア順に並べます。短期・長期の評価は補助情報です。

- 対象銘柄は `scan.py` の `UNIVERSE_JP`（コード・会社名・業種の組）で管理します。日経225などへの拡大は、このリストの差し替えだけで行えます。2026-10-29 に全銘柄の実データ取得で、上場とティッカー形式を確認しました（9613 は上場廃止のため含めず、4307 に差し替え済みです）。
- 取得は25銘柄ずつの一括取得（期間は2年）を使い、取れなかった銘柄だけ個別取得（再試行つき）で取り直します。取得結果は15分キャッシュされます。
- ランキングに入るのは、中期評価ができて、データが「古い可能性」でない銘柄だけです。新旧判定が「間隔あり」の銘柄は、週末・休場で通常に起こる間隔のため、警告を付けて含めます。取得失敗・データ不足・古いデータの銘柄は、理由つきで「参考外」に分けます。
- 並び順は、中期スコア→長期スコア→短期スコア→コード順で、常に同じ結果になります。
- スキャン結果はCSVで保存できます（ランキングと参考外を1つのファイルにまとめています。復元機能はありません）。
- 上位の銘柄は「条件がそろった銘柄」であって、将来の値上がりを予測するものではありません。

## 判定方法（ルールベース）
- 短期（最低30本）：EMA5とEMA20の位置関係、直近5営業日の値動き、RSI14
- 中期（最低80本）：EMA20とEMA50の位置関係、終値とEMA20、直近20・60営業日の値動き
- 長期（最低250本かつEMA200が有効な場合のみ）：EMA50とEMA200、終値とEMA200、直近60・120営業日の値動き
- 本数が不足する区分はスコアを出さず、判定保留／判定不可と表示します
- スコアは条件の一致度であり、勝率や利益を予測するAIではありません

## iPadでの無料公開手順
1. GitHubで新しい別リポジトリ `stock-ai-lab` を作成します（AIFXのリポジトリとは別です）。
2. このフォルダのファイルを新リポジトリに反映します。
3. Streamlit Community Cloud（https://share.streamlit.io/）にGitHubでサインインします。
4. Create appから、新リポジトリ・`main`ブランチ・`app.py`を指定してDeployします。Pythonバージョンは3.12を選んでください。
5. 公開URLをSafariで開きます。

## 重要
- データ取得に失敗した場合（通信エラーや一時的な取得制限で空の結果が返る場合）は、短い間隔を置いて1回だけ再試行します。再試行しても取得できない場合は失敗として明示し、有料データへは切り替えません。
- AIFXの既存リポジトリ、Actions、Artifact、履歴は変更しません。本アプリは完全に独立しています。
- 自動発注・証券口座接続はありません。
- 完全無料の構成です。有料API・有料データは使いません。無料データが取得できない場合は、取得失敗をそのまま表示します。
- 無料データには遅延・欠落・取得制限があります。デイトレードのリアルタイム判断には使わないでください。
- データの新旧は暦日による暫定チェックです。公式の営業日カレンダーとは照合していません。
- 仮想売買メモはセッション内保存です。CSVを定期的にダウンロードしてください。
- `yfinance`のデータ利用条件を確認してください。公式ドキュメントでは個人利用・研究用途について注意書きがあります：https://ranaroussi.github.io/yfinance/
